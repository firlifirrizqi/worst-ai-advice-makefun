# Worst AI Advice

One line of the worst possible advice an AI could give, written for the [Make.fun bounty](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

`main.py` writes the line to `/output/entry.txt`:

> To fix failing tests, delete them — no tests, no bugs.

Run it with `python3 main.py`.
